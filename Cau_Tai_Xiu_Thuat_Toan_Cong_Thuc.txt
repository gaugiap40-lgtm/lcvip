==================================================
- Theo số nhịp: 1 nhịp, 2 nhịp, 3 nhịp, 4 nhịp, 5 nhịp, n nhịp
- Theo hướng: bệt, đảo, đối xứng, so le, nghiêng, gãy, bẻ, chuyền
- Theo chu kỳ: ngắn, trung, dài
- Theo trạng thái: ổn định, chuyển tiếp, nhiễu
- Theo độ rõ: rõ, mờ, tối
- Theo số cửa: 2 cửa
- Theo biên độ: nhịp đều, nhịp lệch, nhịp tăng, nhịp giảm
- Theo điểm gãy: gãy đầu, gãy giữa, gãy cuối
- Theo kiểu lặp: lặp hoàn toàn, lặp có biến tấu, lặp đảo
- Theo số nhánh: 1 nhánh, 2 nhánh, 3 nhánh, 4 nhánh
- Theo dạng đồ thị: bậc thang, sóng, parabol, sin, cos, tam giác, hình quạt

==================================================
PHẦN C: CÔNG THỨC TỰ SINH THÊM DẠNG CẦU
==================================================
- Cầu a-b: với a, b là số nguyên dương. Ví dụ 1-2, 3-5, 7-4...
- Cầu a-b-c: với a, b, c là số nguyên dương. Ví dụ 1-2-3, 4-1-2...
- Cầu a-b-c-d: với a, b, c, d là số nguyên dương. Ví dụ 1-2-3-4...
- Cầu a-b-c-d-e: với a, b, c, d, e là số nguyên dương.
- Cầu bệt n: T T T... n lần rồi X X X... n lần.
- Cầu đảo n: T X T X... n lần.
- Cầu đối xứng: a-b-b-a, a-b-c-b-a...
- Cầu phản đối xứng: a-b-c-d... rồi đảo ngược.
- Cầu Fibonacci: 1-1-2-3-5-8...
- Cầu số học: 1-2-3-4-5...
- Cầu hình học: 1-2-4-8-16...
- Cầu lặp có biến tấu: 1-2-3 rồi 1-2-4, 1-3-3...
- Cầu gãy: đang bệt thì đổi cửa.
- Cầu bẻ: đang 1-1 thì thành bệt.
- Cầu chuyền: nhịp nối tiếp có biến tấu.
- Cầu ma: chuỗi khó nhận biết.
- Cầu không rõ: ra ngẫu nhiên, không theo nhịp.

---------------------------------------------------------------------
2.1. MÃ HÓA
---------------------------------------------------------------------
- Tài Xỉu: T = 1, X = 0
Chuỗi: s = s[0], s[1], ..., s[n-1], s[i] ∈ {0,1}

---------------------------------------------------------------------
2.2. RUN-LENGTH ENCODING (RLE) – CỐT LÕI
---------------------------------------------------------------------
Tách chuỗi thành các đoạn cùng giá trị:
L = [(v1, l1), (v2, l2), ..., (vk, lk)]
Trong đó li = số lần lặp liên tiếp của giá trị vi.

Ví dụ:
T T X X X T X
=> [(T,2), (X,3), (T,1), (X,1)]
=> dãy nhịp: L = [2, 3, 1, 1]

Từ L suy ra cầu:
- L = [1,1,1,1] → 1-1
- L = [2,2,2,2] → 2-2
- L = [3,3,3,3] → 3-3
- L = [1,2,1,2] → 1-2
- L = [2,1,2,1] → 2-1
- L = [1,2,3,1,2,3] → 1-2-3

---------------------------------------------------------------------
2.3. PHÁT HIỆN CHU KỲ
---------------------------------------------------------------------
Chuỗi s có chu kỳ p nếu:
s[i] == s[i - p] với mọi i >= p

Ý nghĩa:
- p = 2 → 1-1
- p = 4 → 2-2
- p = 6 → 3-3
- p = 3 → 1-2 hoặc 2-1

---------------------------------------------------------------------
2.4. PHÁT HIỆN CẦU TỪ DÃY NHỊP
---------------------------------------------------------------------
Cho L = [l1, l2, ..., lk]. Tìm chu kỳ của L.
Nếu L lặp lại mẫu [a,b,...] thì đó là cầu a-b-...

Ví dụ:
L = [1,2,1,2,1,2] → cầu 1-2
L = [3,1,3,1,3,1] → cầu 3-1
L = [2,3,2,3,2,3] → cầu 2-3

---------------------------------------------------------------------
2.5. NHỊP TRUNG BÌNH (đơn giản)
---------------------------------------------------------------------
Nhịp trung bình = n / k
(n = độ dài chuỗi, k = số đoạn RLE)
→ Giúp biết nhịp đang dài hay ngắn.

---------------------------------------------------------------------
3.1. THUẬT TOÁN RLE
---------------------------------------------------------------------
def rle(s):
    out = []
    cur = s[0]
    count = 1
    for x in s[1:]:
        if x == cur:
            count += 1
        else:
            out.append((cur, count))
            cur = x
            count = 1
    out.append((cur, count))
    return out

---------------------------------------------------------------------
3.2. THUẬT TOÁN TÌM CHU KỲ
---------------------------------------------------------------------
def tim_chu_ky(s):
    n = len(s)
    for p in range(1, n // 2 + 1):
        ok = True
        for i in range(p, n):
            if s[i] != s[i - p]:
                ok = False
                break
        if ok:
            return p
    return None

---------------------------------------------------------------------
3.3. THUẬT TOÁN TÌM CẦU TỪ NHỊP
---------------------------------------------------------------------
def tim_cau_tu_nhip(L):
    n = len(L)
    for p in range(1, n // 2 + 1):
        ok = True
        for i in range(p, n):
            if L[i] != L[i - p]:
                ok = False
                break
        if ok:
            return L[:p]
    return None

---------------------------------------------------------------------
3.4. THUẬT TOÁN PHÂN LOẠI CẦU
---------------------------------------------------------------------
def phan_loai_cau(s):
    L = rle(s)
    nhip = [count for _, count in L]
    
    if len(L) == 1:
        return "Bệt"
    
    cau = tim_cau_tu_nhip(nhip)
    if cau:
        return "Cầu " + "-".join(map(str, cau))
    
    if nhip == nhip[::-1]:
        return "Đối xứng"
    
    return "Hỗn hợp / không rõ"
